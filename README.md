# APEX / CXALLOY Local 下载

本仓库仅用于分发 Windows 64 位安装包和程序更新，不包含应用源码或用户数据。

## 下载与安装

前往 [Releases](https://github.com/markbryant7787-hub/cxalloy-releases/releases)，选择最新测试版，展开 Assets，下载 `CXALLOYLocal-版本-windows-x64-setup.exe`。

首次版本尚未出现时，表示安装包仍在构建或发布配置中，请稍后查看。
无需自行安装 Python、Chromium 或部署服务器。安装包尚未进行代码签名。

## 更新

使用旧私有发布渠道的 beta.10 及更早版本，需要手动覆盖安装 beta.11 或后续版本一次。
安装版随后可在程序内“检查更新 → 确认下载 → 确认安装并重启”。有未完成任务时不能安装更新。
源码版、免安装版或自定义数据目录请手动更新。
升级保留本机配置、任务与登录状态；重要数据仍建议自行备份。

## 使用范围

测试版请先预览并小范围验证。仅在你有权访问的业务系统中使用。
这里的下载文件公开可见；公开分发不代表授权访问任何 CXALLOY 账号、项目或业务数据。
